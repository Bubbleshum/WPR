WPR — Windows Phone Xbox LIVE Compatibility

Every Xbox LIVE–enabled Windows Phone game WPR aims to run, with a separate verdict for Windows desktop and Android on the .NET 8 + Avalonia 11.3.9 fork. Most titles are still Untested — that’s the to-do list, not a verdict — and Android testing has only just started, so nearly every Android verdict is still blank.
