**A small fix for Windows: you can uninstall games again.**

| | |
| --- | --- |
| 🗑️ | **Uninstall works on Windows.** The question it asks ("delete the save data too?") had its Yes / No / Cancel buttons cut off below the bottom of the window, so there was no way to answer it |

The same window is used for every question WPR asks on Windows, so other long questions show
their buttons now too. Closing one of these windows with its X now counts as "Cancel" instead of
leaving WPR waiting for an answer.

Nothing changes on Android.

> **Upgrading is normal.** Run the installer on Windows. Your games, saves and sign-in stay put.
