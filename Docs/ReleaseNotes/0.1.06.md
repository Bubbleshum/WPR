Five games that used to show an error instead of starting now run, three more that used to fail in
other ways play, and every game finally gets its own saved data.

**Cut the Rope plays end to end** — and so do **Cut the Rope: Experiments**, **Little Acorns**,
**Rabbids Go Phone** and **Flight Control Rocket**. **Carcassonne's menu works**, and
**Sid Meier's Pirates!** and **Galactic Reign** put their opening screens on the display for the
first time. None of them was ever really broken; they are built a way WPR had no support for.

**The Treasures of Montezuma, Plants vs. Zombies and iStunt 2 all play**, each after a fault of its
own — one of them WPR's own doing, and one that had been closing a whole family of games on Android.

**Every game now keeps its own saved data.** Until now they shared one save area, so two games that
happened to use the same file name could break each other — playing **Fragger** was enough to stop
**Gravity Guy** loading at all. Existing saves are carried over, and a single game's data can now
be cleared if it ever gets into a bad state.

**Android now needs Android 7.0 or newer**, because WPR runs on a different .NET engine there than
it used to. Windows is unaffected.

> **Upgrading is normal.** Install the new APK straight over the top on Android, or run the
> installer on Windows; your games and progress stay where they are.
>
> **Android 7.0 is now the minimum**, up from Android 5.0. This release runs on a different .NET
> engine, and that engine is not offered for older versions. If you are on Android 5 or 6, stay on
> **0.1.05** — it keeps working, it just will not get newer releases. Windows is unchanged.
>
> **Every game needs to be repatched once**, as in 0.1.05. On **Android this is automatic** — the
> first launch of each game says *updating patched assemblies…* for a moment and carries on. On
> **Windows it is not**: press **Repatch** on a game's page, or start WPR with
> `--repatch-installed` to do the whole library and exit.
>
> The repatch is what applies both the games below and the saved-data fix, so if a game has
> been sitting in your library doing nothing — or losing your scores — repatch it.
>
> The repatch also moves each game onto **its own saved data**. The first time a game runs after
> that, its existing saves are copied across automatically, so nothing is lost and there is nothing
> to do.
