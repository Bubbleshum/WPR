**Hexic plays, with sound, cloud saves and your gamer picture, and Windows Phone 8 games can now talk to WPR Hub.**

| | |
| --- | --- |
| 🔷 | **Hexic plays**: title, tutorial, levels and the map, with music and sound effects |
| ☁️ | **Cloud saves through WPR Hub**: Hexic keeps your progress on WPR Hub, so a fresh install picks up where you left off |
| 🖼️ | **Your gamer picture in Windows Phone 8 games**: Hexic shows your WPR Hub gamerpic beside your gamertag |
| 🏆 | **Hexic's achievements screen opens** instead of stopping the game, and shows each achievement's picture |
| 🎬 | **Need for Speed: Hot Pursuit's intro plays once**, not twice |
| 📱 | **Games keep their place on Android** when you switch away and back, instead of restarting from their splash screen |

### Windows Phone 8 games and WPR Hub

- **Games that call Xbox LIVE's web services reach WPR Hub.** A Windows Phone 8 game's own web
  requests now go to WPR Hub when the hub serves that service for the game, and the game gets the
  hub's real answer. Everything else still fails as "no connection", as before.
- **Hexic's cloud save** is stored on WPR Hub under your account. Clear the game's data or install it
  on another device, sign in, and your profile comes back.
- **Your gamer picture.** Signed in, Windows Phone 8 games that show the player's picture get your
  WPR Hub gamerpic. Signed out, they keep their own default picture.
- **Achievement pictures** come from WPR Hub's achievement icons.

### Hexic

- **It runs**: title screen, tutorial, levels, the level map and "Really quit?".
- **Sound**: music and effects play. The game's sound engine couldn't find its sound bank before.
- **Signing in finishes**: the game no longer sits on "signing in" for ever.
- **Smoother**: the game no longer logged a warning on every draw, which slowed it to about 17 fps.
- **Achievements**: opening the achievements screen used to stop the game. It now opens and shows
  all 15 achievements.

### Fixes

- **Need for Speed: Hot Pursuit**'s intro played twice: its movie file asks for the video to be
  played twice over, but the phone only ever played it once. WPR now stops a movie at the length its
  file says it is, with nothing to reinstall.
- **Android: a game no longer restarts when you come back to it** after a change such as a keyboard
  connecting, the screen size or layout changing, or dark mode switching. Bejeweled Live+ restarted
  from its splash screen every time it returned from the background.
- **Windows Phone 8 games that share data between threads**: WPR now switches between a game's
  threads the way a real phone does in two more respects, closing a gap that could, rarely, lose an
  update one thread made.

### Known issues

- **Hexic's achievements screen on Android** sometimes shows the default picture for one or two
  achievements instead of their own. Windows shows them all.
- **Hexic's special offers** button stops the game, because WPR's store lists nothing for sale.
- **Unity games for Windows Phone 8** still show a black screen.
- **Application bars** (the row of round buttons at the bottom of some Silverlight pages) still
  aren't drawn.
- Tested on Windows and a Galaxy S24. Not tested on a Mali-based phone.

> **Upgrading.** Install the new APK over the top on Android, or run the installer on Windows. Your
> games, saves and sign-in stay put. Installed games update themselves the first time you start them.
