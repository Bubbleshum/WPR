### Racing (Windows Phone 8)

- **No more stutter as new scenery appears.** Phones can't use the compressed textures these games
  ship, so WPR unpacks them. That now happens on other CPU cores as soon as the game asks, and 3.4
  times faster, instead of in the middle of drawing a frame.
- **Cars no longer teleport when they crash.** A game thread that checks the clock in a tight loop
  could see time jump up to 0.4 s in one go. It now sees no more than a frame passing.
- **Frames arrive on time.** The game now prepares one frame ahead, so a frame that takes a little
  too long no longer leaves the previous picture on screen twice.
- **Faster to a race the second time.** The phone keeps the graphics setup it built for each game,
  so it doesn't rebuild it every time you play.

### Frame rate

- **Windows Phone 8 games that cap their own frame rate are held to it**, as they were on the phone.
  Asphalt 7 asks for 30 fps and now gets a steady 30, with every frame shown for the same time;
  until now it ran uncapped, which used more power for no gain in a game made for 30.
- **The game's waits are lined up with your screen's refresh**, so a game that asks for 30 gets an
  even 30 rather than 28 with an occasional frame held longer (a judder you could feel when racing).

### Memory (3-4 GB phones)

- **Less graphics memory.** A light game like Brick Breaker now takes about 95 MB of graphics memory
  instead of 236 MB, and an Asphalt 7 race about 230 MB instead of 430 MB.
- **Less of WPR's own memory.** Textures and model data are dropped once they're on the graphics
  card. WPR's own memory in an Asphalt 7 race fell from about 300 MB to about 105 MB.

### Fixes

- **Location.** Games that look up where you are now start, and are told location is turned off
  (WPR doesn't share your location). This fixes Secrets and Treasures: The Lost Cities and Tentacles.
- **Closing a game while it loads (Android)** no longer shows "the game exited unexpectedly" or files
  a crash report. Your game list also no longer freezes for a moment after every game.
- **Windows Phone 8.1 game names.** Some games showed a code like `@Global/AppResLib.dll,-200`
  instead of their name. Reinstall an affected game to fix its name.

### Known issues

- **FIFA 13** now runs at its own 24 fps, so its menus and matches should run at the right speed.
  This hasn't been tested in a match yet.
- **Unity games for Windows Phone 8** still show a black screen.
- **Application bars** (the row of round buttons at the bottom of some Silverlight pages) still
  aren't drawn.
- Tested on Windows and a Galaxy S24. Not tested on a Mali-based phone.

> **Upgrading.** Install the new APK over the top on Android, or run the installer on Windows. Your
> games, saves and sign-in stay put. Installed games update themselves the first time you start them.
