### Windows Phone 8 games for the ARM chip

Most Windows Phone 8 games are .NET, like the Windows Phone 7 games WPR has always run. Some,
mostly the big ones, were written in C++ and built for the phone's ARM processor, so there was
nothing for WPR to run. WPR now runs that ARM code itself, translating it for your PC's or phone's
processor as it goes, and supplies the parts of Windows Phone 8 those games call: graphics, sound,
touch, files, threads and Xbox Live.

Install them like any other game, from their XAP. On Android they need a 64-bit phone, which is
nearly every phone made in the last six years.

### Modern Combat 4

Modern Combat 4 draws in 3D with its own shaders. WPR records each frame the game draws and
replays it on your graphics card with those same shaders, so the jungle, ocean and explosions look
as they did on the phone. It runs at 60 fps on a Windows PC and on a Galaxy S24.

### Known issues

- **Loading is slow on phones.** Modern Combat 4's loading screens run at 1–2 fps on a Galaxy S24
  (10–13 fps on a PC), and its sound drops out while it loads. Once a mission starts it runs at
  60 fps.
- **Sound in WP8 games can still drop out now and then** on Android.
- **Angry Birds Stella stops on its "connecting" screen.** It needs Rovio's sign-in server, which
  no longer exists. Getting past it means WPR answering for that server, and that isn't done yet.
- **Other C++ WP8 games**, such as GTA San Andreas, Asphalt and Rayman, now install but don't start
  yet. Each one needs its own page described to WPR, and so far that's been done for Amazing Alex
  and Modern Combat 4.
- **Modern Combat 4's briefing videos are skipped.** There's no video player for these games yet.

> **Upgrading is normal.** Install the new APK over the top on Android, or run the installer on
> Windows. Your games, saves and sign-in stay put. Nothing needs repatching or reinstalling. A WP8
> game you installed before this release (when it couldn't run) needs reinstalling from its XAP.
