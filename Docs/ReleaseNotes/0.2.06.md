### Windows Phone 8 games

WPR now supplies everything Windows Phone 8 games ask the phone for, across the 102 native games
in our test library. That doesn't make every game run, but each one now gets as far as its own
code allows. Games that bring their own helper libraries load them, and network code gets real
connections. Windows Phone 8 games also see a sharper 1280x768 screen, like a Lumia 920.

Games built around a page that hosts the native game (most big WP8 titles) used to stop at once
unless WPR had been told about that page. WPR now works the page out from the game itself, so about 30
more titles get past that point. Most still stop a little later; see known issues.

Angry Birds games that quit when you press Back on their main menu are no longer reported as
crashing. Games now pause properly when you switch away and resume when you come back, and a held
key repeats on Windows.

### Silverlight games on Android

There is now one Silverlight player, the same on Windows and Android. Pure Silverlight games such
as Flowerz and Minesweeper run on phones for the first time. The player also draws circles, lines,
shapes, buttons and pop-ups that used to be missing or drawn as plain boxes. On Windows, these games
now open in a game window like any other game, without the phone frame around them.

### Sound and movies

Windows Phone 7 movies play on Windows and Android. On Android, the music player was rewritten, so
it no longer clicks every second, and sound goes straight to Android's low-latency output. Windows
Phone 8 movies play on both too, Halo's included.

### Known issues

- **Halo**: some objects and parts of the weapon panel are drawn as black shapes. Missions need
  two fingers at once, so on Windows with a mouse you can't start one.
- **Assassin's Creed Pirates** freezes for about 30 seconds after you press Play while it loads.
- **Many newly reached WP8 games stop early**, including Asphalt Overdrive, Fruit Ninja, Jetpack
  Joyride, Hexic, Bubble Guriko and Doodle God Blitz. Unity games and the WP8 Microsoft Minesweeper
  show a black screen.
- **Big Buck Hunter Pro** stops on its loading screen when a hunt starts.
- **Modern Combat 4** isn't paused by a phone call or the lock screen.
- **Not tested on a Mali phone.** Most of this release was tested on Windows and the Android
  emulator. Only some of it was tested on a Galaxy S24.

> **Upgrading is normal.** Install the new APK over the top on Android, or run the installer on
> Windows. Your games, saves and sign-in stay put. Installed games are updated automatically the
> first time you start them. Two exceptions: **to get movies on Android**, re-patch any game with
> cutscenes installed before this release (long-press it → re-patch), Halo included. And
> **reinstall** the WP8 Microsoft Minesweeper and What In The World? from their XAPs, plus any game
> whose name shows as "@AppResLib.dll,-100".
