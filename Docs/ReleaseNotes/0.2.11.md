### SDL3

WPR's lowest layer moved from SDL2 to SDL3 on both platforms: the game window, touch and keyboard,
graphics setup, game sound and music, and microphone recording. You shouldn't notice it, apart from
the fixes below. Game sound on Android now goes through SDL's own low-latency output, which pauses
when you leave a game and picks up again when you come back.

### Screen orientation (Android)

- **Each game decides which way the screen faces.** A portrait game opens in portrait and a
  landscape game in landscape, chosen from what the game itself asks for. Bejeweled LIVE+ and
  Doodle Jump no longer come up as a landscape picture cut off on the right.
- **Games that support every orientation follow the phone**, as they did on Windows Phone.
  Bejeweled LIVE switches between its portrait and landscape layouts as you turn the phone. Your
  rotation lock is respected.

### Speed and stability

- **Bejeweled LIVE runs at full speed.** It asks for 100 game updates a second; WPR used to cap that
  at 60, so the whole game ran at 60% speed. It also draws more smoothly now.
- **Leaving a game is safe.** Pressing Home or switching apps mid-game could crash the game on its
  way to the background. It now waits until you come back and carries on.
- **Windows Phone 8 games load faster.** Games that open the same archive thousands of times while
  loading (Modern Combat 4 opens one about 3,000 times) now share one open file, and checking a file's
  details no longer touches storage. Modern Combat 4's first loading screen spends about a third as
  long on files.

### Vibration and sensors (Android)

- **Vibration goes through SDL**, using the phone's own motor at full strength.
- **The vibration switch in Settings is gone.** Games that vibrate have their own setting for it, as
  on Windows Phone. If you had turned WPR's switch off, games will vibrate again until you turn it
  off in the game.
- **Tilt and the gyroscope** are read through SDL, about 60 times a second.

### Under the hood

- **16 KB memory pages.** Newer Android phones use 16 KB memory pages and need every native library
  built for them. All of WPR's now are, including the media tools that convert WMA music and game
  videos when you install a game.
- **Leaner media tools.** Those tools were rebuilt from source with only the parts WPR uses.

### Known issues

- **Bejeweled LIVE now starts in whichever way you hold the phone**, where WPR used to force it into
  portrait. That's the game's own choice.
- **FIFA 13 matches play faster than they should.** Windows Phone 8 games run at full frame rate
  here, but FIFA moves its match a fixed step per frame and was made for 24 frames a second.
- **Unity games for Windows Phone 8** still show a black screen.
- **Application bars** (the row of round buttons at the bottom of some Silverlight pages) still
  aren't drawn.
- Tested on Windows and a Galaxy S24. Not tested on a Mali-based phone.

> **Upgrading.** Install the new APK over the top on Android, or run the installer on Windows. Your
> games, saves and sign-in stay put. Installed games don't need updating for this release.
