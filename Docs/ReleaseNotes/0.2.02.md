### Leaderboards

Most Windows Phone games post a score one way and read it back another: they set the score as the
board's *rating*, then look it up in a column called "BestScore" (or "BestTime" on timed boards).
Xbox LIVE filled that column in for them. WPR Hub didn't, so every score on the board read as 0,
even though the real scores were on the hub. WPR now fills it in the same way Xbox LIVE did.

### Gamerpics

Windows Phone games were written for a 64×64 gamer picture and draw it at whatever size they're
given. WPR was handing them the hub's 256×256 one. Games now always get 64×64. On leaderboards,
each player now carries their own picture from the hub, where before every row showed yours.
(Some games, Fruit Ninja among them, only ever draw yours. That's how they were made.)

### Fruit Ninja's gamerpic button

Tapping your gamerpic on Fruit Ninja's main menu asks the phone to open your Xbox LIVE gamer
card. WPR has no gamer card to show and reported an error instead, which left the menu stuck
halfway through the tap and ignoring every touch after it. It now just carries on, as if you'd
looked and come straight back. The same goes for the other Xbox LIVE screens a game can ask for:
friends, messages, marketplace and the rest.

### Asphalt 5

Phone graphics chips can't use the compressed texture format most Windows Phone games shipped
with, so WPR unpacks those textures. The unpacked textures used to tell the game they had never
been compressed, and Asphalt 5 uses that answer to decide which car parts it can repaint. It picked
the wheels, failed on every frame, and the race never loaded. Textures now report the format the
game shipped, so it takes the same path it did on a real phone.

### Doodle God, and resuming games

When a game got the focus back, WPR told it the app was starting from scratch instead of resuming.
Doodle God's "quit?" box takes the focus, so answering NO made it reload everything a second time,
and crash. Games are now told they resumed, as a Windows Phone would. This applies to every game.

### Signing in to WPR Hub

Android cuts off the network connections of apps in the background, so the first check after you
came back from approving the key could fail, and WPR gave up on the whole sign-in. It now just
tries again until you approve or the key expires.

> **Upgrading is normal.** Install the new APK over the top on Android, or run the installer on
> Windows. Your games, saves and sign-in stay put. Nothing needs repatching or reinstalling.
