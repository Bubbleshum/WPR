## Feasibility studies

Scoping work on game families that can't simply be hosted in-process — and, for WP8
native titles, one that turned out to be hostable after all.

| Doc | Verdict |
| --- | --- |
| [Unity_WP8_Feasibility.md](Unity_WP8_Feasibility.md) | Unity WP titles: **no-go in-process** even with the ARM CPU (track 4 spike, 2026-10-12, §11): `UnityEngine.dll`'s ~2,900 native function pointers assume one shared 32-bit address space. They *are* recoverable by a one-time per-game rebuild that WPR launches instead; the launcher rail is implemented, no per-game port is. The same spike found Spark2 a **go**, and AC Pirates now runs in-process to its first mission on desktop. |
| [Spark2_Managed_Reimplementation_Feasibility.md](Spark2_Managed_Reimplementation_Feasibility.md) | Ubisoft's Spark2 engine (AC Pirates): a managed reimplementation is **not practically feasible**. **Superseded as a route** by running the game's own ARM code (`Unity_WP8_Feasibility.md` §11), which does the AES decryption itself. Kept for its analysis of the engine. |
| *(both WP8-NATIVE docs below)* | **History.** The probe they describe is no longer a branch-only experiment: its sources (formerly `Research/Wp8Native/`) are `Src/Engine/WPR.Engine.Wp8Native/Runtime/`, on dynarmic, and WP8 native titles launch from both heads. See [`Docs/ARCHITECTURE.md`](../Docs/ARCHITECTURE.md) for the current state. |
| [WP8-NATIVE-RESUME.md](WP8-NATIVE-RESUME.md) | WP8 native (C++/DirectX) titles: **feasible, demonstrated** in an ARM probe that lives on the `wp8-native` branch (worktree `.claude/worktrees/wp8-native`). This page is the pointer: where the work is, its state, and how to resume it. The full plan and measurements are on that branch. |
| [WP8-NATIVE-PROBE.md](WP8-NATIVE-PROBE.md) | WP8 native (C++/DirectX) titles: **feasible, and demonstrated** — an ARM probe boots Angry Birds Rio to its menus and drives them with touch. Two known blockers, both measured: one bug in the game's own Lua, and a CPU that must move to dynarmic for both licence and speed. |
